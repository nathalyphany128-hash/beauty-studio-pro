# 💇‍♀️ Beauty Studio Pro

Sistema web desenvolvido para auxiliar no gerenciamento de um salão de beleza, permitindo o controle de clientes, funcionários, serviços e agendamentos.

## 📌 Sobre o projeto

O **Beauty Studio Pro** foi desenvolvido como projeto acadêmico durante o curso de **Gestão da Tecnologia da Informação**, na disciplina de Desenvolvimento Web com HTML5, CSS, JavaScript, PHP e Banco de Dados.

O objetivo do sistema é facilitar a organização das atividades de um salão de beleza, centralizando informações e permitindo o gerenciamento dos principais registros do estabelecimento.

## 🗄️ Banco de dados

O sistema utiliza **MySQL** para armazenamento e gerenciamento dos dados.

### Banco de dados

`beauty_studio_pro`

### Tabelas

- `clientes`
- `funcionarios`
- `servicos`
- `agendamentos`

O projeto utiliza operações **CRUD**:

- **Create** — criação de registros
- **Read** — consulta de registros
- **Update** — atualização de registros
- **Delete** — exclusão de registros

O arquivo `beauty_studio_pro.sql` contém a estrutura do banco de dados utilizada pelo projeto.

## 💻 Como executar o projeto

### Pré-requisitos

- XAMPP
- PHP
- MySQL
- Navegador web

### Instalação

1. Instale o XAMPP.
2. Copie a pasta do projeto para a pasta `htdocs`.
3. Inicie o **Apache** e o **MySQL** pelo painel do XAMPP.
4. Abra o **phpMyAdmin**.
5. Crie o banco de dados `beauty_studio_pro`.
6. Importe o arquivo `beauty_studio_pro.sql`.
7. Acesse o projeto pelo navegador:

`http://localhost/beauty_studio_pro`

## 🎨 Interface

A interface foi desenvolvida utilizando HTML5, CSS3 e JavaScript, com identidade visual voltada para o segmento de beleza.

O sistema possui página inicial, menu de navegação, formulários de cadastro, listagem de registros, botões de edição e exclusão e mensagens de confirmação.
